# Information Security Portfolio

A responsive, single-page academic portfolio for an Information Security student at the National University of Sciences and Technology (NUST). It uses the Prologue template by HTML5 UP.

## Design and assets

The template's single-page scrolling navigation, responsive sidebar menu, and mobile breakpoints are retained. The portfolio palette and card styles are defined in `assets/sass/main.scss` and included in the published stylesheet, `assets/css/main.css`.

The Projects navigation link and the introductory project button both target the `portfolio` section. The button uses the template's Scrolly plugin for smooth scrolling.

The original Prologue license is retained in `LICENSE.txt`. Prologue is by [HTML5 UP](https://html5up.net), designed by AJ, and is distributed under the [Creative Commons Attribution 3.0 License](https://html5up.net/license). The existing `README.txt` contains the template's original credits.
